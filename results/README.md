# Results

This directory contains analysis outputs generated during the TREM2 rare
variant association workflow.

Only compact, human-readable summaries and logs are intended to be
tracked in GitHub. Large or genotype-containing intermediate files
generated by PLINK are excluded from version control.

## Input Inspection Results

The initial data inspection scripts generate:

```text
vcf_inspection.txt
covariates_inspection.txt
```

## Retained QC Outputs

Only compact QC summaries and logs are retained in the repository.

Retained files include:

```text
results/qc/
├── qc_summary.tsv
├── 00_raw.log
├── 01_geno.log
├── 02_hwe_controls.log
├── 02_hwe.log
├── 03_mac.log
└── 04_final.log
```

`qc_summary.tsv` records the number of variants before and after each
PLINK QC step. The PLINK log files are retained to document the commands,
settings, and filtering performed at each stage.

## Retained VEP Outputs

Compact files describing the final TREM2 functional variant
classification are retained:

```text
results/vep/
├── trem2_variant_classes.tsv
├── trem2_lof_variants.txt
├── trem2_missense_variants.txt
└── vep_annotations.tsv
```

`trem2_variant_classes.tsv` records the final functional classification
for each unique TREM2 variant. The LoF and missense variant lists contain
the variants used for the corresponding SKAT-O tests. `vep_annotations.tsv` 
contains full vep annotation table.

## Retained SKAT-O Outputs

The final SKAT-O results and reproducibility information are retained:

```text
results/skat/
├── skato_results.tsv
├── skato_model.txt
├── R_session_info.txt
└── 05_run_skato.log
```

`skato_results.tsv` contains the number of variants included in each
SKAT-O test and the resulting P-values. `skato_model.txt` records the
covariate-adjusted model, `R_session_info.txt` records the R and package
environment, and `05_run_skato.log` contains the console output from the
analysis.

## Excluded Intermediate Files

Large or subject-level intermediate files are not tracked in GitHub,
including:

```text
*.pgen
*.pvar
*.psam
*.raw
*.vcf
*.vcf.gz
```

These files contain genotype data or are reproducible intermediate files
and can be regenerated by running the scripts documented in the main
project README.
